## Getting started  
### Dependencies  
- Node.js  
- npm  
- Windows i guess  
### Installation  
- clone the repo by running  
```git clone https://github.com/Ahad732/KAE-Studio-Site```
- go into the directory  
```cd KAE-Studio-Site```  
- install dependencies or whateves by running  
```npm install```  

### Execution  
- open your favourite terminal app  
- start local dev server  
```npm run dev```  
- open browser and go to localhost:4321
